> ⚠️ **제품명이 서로 다르다.** 공식 사이트는 *Trust CA + Trust Gateway* 두 제품, Codex 사이트는 *Trust Gateway + Trust MFA + Trust One Login* 세 제품이다. 새 사이트는 **공식 사이트(실제 사업 기준)를 정답으로 보고 Codex 사이트의 이름은 폐기하거나 하위 기능명으로 정리**하는 것이 안전하다. 확인이 필요하다.

공식 사이트의 확인된 콘텐츠(재사용 가능): 3가지 강점(핵심 기술 내재화 / 베트남 해외 파트너 / 맞춤형 IT), 서비스 3종(Web·iOS·Android / 글로벌 ODC / PI 컨설팅), 고객 레퍼런스(KB국민카드 통합인증, 롯데카드 보안 컨설팅, 여신금융협회 직승인, 웰컴저축은행 모바일 인증 + E-Mart·현대백화점·롯데쇼핑·AK플라자·신세계·dot::·ThePay·CJ/대우), 성공 사례(Airrain BPI, 점자 변환 솔루션, NFC 결제 모듈, Salesforce), 보안 철학 3원칙(Always Verify / Least Privilege / Assume Breach), 도입 3단계, 회사 소개·임원진·파트너, 연락처.

### 0-B. 기존 → 새 사이트에서 바뀌는 점
- 공식 사이트는 **4개 화면이 한 파일**이라 검색 노출·공유·분석이 불리하다 → 새 사이트는 **페이지마다 고유 URL**
- 홈에 *Get a Demo / Contact*가 이미 있어서 packetgo식 CTA 구조와 잘 맞는다
- 공식 사이트에 **뉴스·자료실·용어집·파트너 페이지가 없다**(레퍼런스에서 가져올 가치가 가장 큰 부분)

### 0-C. 색은 "파랑 vs 보라"가 아니라 이미 *다크 네이비 + 인디고/바이올렛*이다
공식 사이트 팔레트(`#90AAFF`, `#B89AFF`, 민트 `#4DD8C2`)는 PacketGo의 보라와 계열이 가깝다. 따라서 **보라 전환이 아니라 "기존 인디고 계열을 밝은 베이스로 확장"** 하는 쪽이 자연스럽고, PacketGo의 채도 높은 보라 `#7C27E5`는 그대로 쓰지 않는다.

### 0-D. PacketGo(ZTNA)는 Trust Gateway와 같은 시장의 경쟁 제품이다
구조·패턴·UX는 참고해도 되지만 **문구, 이미지, 3D 구체, 로고, 일러스트, 색을 그대로 가져오면 "복제 사이트"로 보이고 저작권·신뢰 리스크**가 된다. "카피"는 *뼈대와 패턴*까지만으로 잡는 것을 권한다.

> 그리고 새로 받은 피드백: **packetgo의 "휠을 내려야 진행되는" 스크롤 연동 히어로는 답답하다** → 아래 설계에서 제외한다.

### 3-1. 폴더 구조
- 총 **1,342개** `.md` (브랜드명 기준 약 1,288개, 같은 브랜드 중복 버전 있음: 예 Apple 5개)
- 모든 파일이 같은 템플릿: *테마(light/dark/mixed) → 분위기 한 줄 → 색 토큰 → 타이포 → 간격·반경·그림자 → 컴포넌트*
- 테마 분포: light 916 · dark 293 · mixed 133
- `index.json`은 url/title/file/bytes뿐이라 카테고리 검색은 안 된다 → 한 줄 소개·색·폰트를 뽑아 **직접 색인**을 만들어 키워드(보안·B2B·보라·AI 등)로 걸렀다. (키워드별 보안 246건, 엔터프라이즈 93건, 보라 계열 359건 후보)

## 4. 결정이 필요한 것 (우선순위순)

1. **제품명 정답**: 공식 사이트의 *Trust CA + Trust Gateway* 로 가는지, Codex 사이트의 *Trust Gateway + Trust MFA + Trust One Login* 인지

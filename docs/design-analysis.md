## 4. 유지 · 개선 · 교체 의견

### 유지할 만한 것
- **packetgo**: 완전한 pill 형태의 떠 있는 헤더, 20px/16px 이중 라운드 카드, 연보라 4단 배경으로 섹션 리듬 만들기, 대형 한글 제목에 -2% 음수 자간, vw 기반 유동 타이포, 파트너 로고 마퀴, `prefers-reduced-motion` 대응
- **pribit**: 좌우 교차 스플릿 + 큰 라운드 이미지, 퍼플 풀블리드 섹션을 앵커로 쓰는 리듬, 로고 형태를 섹션 전환 장식으로 쓰는 아이디어(자체 로고로 재해석), 뉴스 게시판 검색 구조

### 개선할 것
1. **디자인 토큰화** — 두 사이트 모두 CSS 변수가 사실상 없음. 색·간격·반경·폰트를 `:root`에 변수로 정의
2. **라이브러리 정리** — pribit의 jQuery·GSAP·ScrollMagic·AOS·Swiper·Slick 중복은 피하고, 모션은 한 가지 체계(예: Lenis + 가벼운 IntersectionObserver)로
3. **접근성** — 부제 색 대비, 키보드 포커스 링, 모션 감소 대응을 기본값으로
4. **브레이크포인트 단순화** — packetgo의 12개는 과다. 480 / 768 / 1024 / 1440 정도로
5. **메뉴 일관성** — packetgo 데스크톱 헤더에 N2SF 누락(푸터에만 존재)
6. **placeholder 제거** — pribit의 "test", "메인 배너2", `#007AFF` 스와이퍼 기본색

### 교체할 것
- pribit의 0px 반경 보조 버튼(다른 요소는 모두 둥근데 혼자 각짐)
- 클래스명 `txt-ico-type3` 같은 번호식 네이밍 → 의미 기반(BEM 등)
- 이미지에만 큰 오프셋 그림자를 쓰는 방식(일관성 부족) → 카드 단위 그림자 규칙 하나로 통일

## 5. 확인하지 못한 부분
- packetgo 리소스 드롭다운 패널의 실제 모양(자동 클릭으로는 열리지 않음)

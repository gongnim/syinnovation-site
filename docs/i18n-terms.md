# English version: style and fixed terms

The English site (`/en/...`) says exactly what the Korean site says, no more and no less. This file is the one source for
how words are translated; every page, component and data file follows it. Started 2026-11-16 from the Korean site and
the Trust Gateway brochure (사내문서/브로슈어, 261116), whose English names win where they exist.

## Style

- US English, plain and specific. Short sentences. Write for an IT or security buyer who reads English as a second
  language as often as a first one.
- Never add a claim, a number, a client name or a capability the Korean text does not state. Never drop a hedge
  ("according to …", "under investigation", "may have", "알려졌습니다", "보도됐습니다").
- Numbers, dates, names, versions and units stay exactly as in Korean. Convert Korean large numbers carefully:
  만 = 10,000, 억 = 100,000,000 (3만5천 = 35,000; 1억 5,300만 = 153 million; 109만 = 1.09 million).
  Money: "KRW 5 billion" (원). Dates in running text: "Nov 16, 2026"; keep ISO dates in data fields.
- No em dash (—) anywhere. Use a comma, a colon, parentheses or two sentences. No exclamation marks.
- Headings and buttons in sentence case ("How Trust Gateway works"), except product and feature names, which keep their
  capitals (Trust Gateway, Trust Auth, Multi-Signal Cross Check).
- Korean particles of emphasis such as 「…」 become plain double quotes.
- Keep "Never Trust, Always Verify" as is.

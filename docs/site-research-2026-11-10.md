## 1. 회사가 파는 것 (11월 문서 기준)

**포지셔닝(최신, IBK 덱):** 멀티 신호 교차 검증 기반 제로트러스트 보안 SaaS, Trust Gateway
**슬로건:** Never Trust, Always Verify. / 브랜드 태그 RE:Think innovation

### 제품: 한 엔진, 3개 영역
| 영역 | 이름 | 상태 | 비고 |
|---|---|---|---|
| 접근 통제 (VPN 대체) | **Trust Gateway** | 주력, 2026.02 출시 | 시연 영상 Track B |
| 통합 인증 | **Trust CA** (MFA · One Login/SSO) | 금융권에서 이미 운영 중인 기술 | KB국민카드·롯데카드·웰컴저축은행 |
| 이상거래 방지 | **Fraud Prevention** | 확장 영역 | 카드 ACS(3DS) 이전 단계 차단, 시연 영상 Track A |

- 이름 충돌: 8~10월 문서·기사는 **TrustIn Gateway(TIG) / TrustIn MFA**, 11월 문서는 모두 **Trust Gateway**. 데모 헤더명 `X-TIG-Identity`.
- 우선순위: 접근 통제(주력) → 인증(운영 중) → 이상거래 방지(확장).

### 작동 방식 (사이트 도식용)
- 세 구역이 서로 신뢰하지 않음: ① 사용자 PC + 휴대폰 ② Trust Gateway 서비스 ③ 고객 사내망
- **PC는 기기를, 폰은 사람을 증명**: QR로 PC↔폰 연결, 폰 생체 승인 후 단기 mTLS 인증서 발급, 개인키는 기기 하드웨어에 봉인
- 휴대폰·PC의 위치·네트워크·시간 신호를 교차 검증, 요청마다 위험 재평가 → 허용 / 폰 재인증 / 차단·인증서 폐기
- 고객망 **들어오는 포트 0개**, 내부 에이전트가 밖으로만 연결(리버스 터널)
- 앱은 게이트웨이가 넣어 주는 서명된 신원 정보로 사용자를 식별(재로그인 없음)
- 배포: 금융·공공 온프레미스, 일반 기업 SaaS
- 도입: PoC 2~4주 → 파일럿 4~8주 → 전사 8~16주 (무료 PoC 기간은 문서마다 1·2·2~4주로 다름)

### 제품 기술서 v0.9.2 (2026-11-09) 기준 정정
- 공식 제품명 **Trust Gateway**. 구성: Trust Gateway for Windows(User Agent), **Trust Auth** for Android(모바일 앱), ZT Gateway, Control Center · CA, 정책·위험 엔진(OPA), Internal Agent. "TrustIn"은 루트 인증서 이름(TrustIn Root CA)에만 등장
- "Trust MFA / Trust One Login / Trust CA / TIG"는 기술서에 없음
- 기술서는 **업무 접근(Track B)만** 다룸. 결제 이상거래(Track A)는 한 문단. 동향 리포트는 TIG를 결제 구간 솔루션으로 따로 씀 → **Trust Gateway와 이상거래 방지가 같은 제품인지 확인 필요**
- 수명주기 7단계: 기기 등록(QR) → 인증서 확인(mTLS) → 터널 준비(WireGuard) → 사용자 결합(폰 승인) → 리소스 접근(정책 평가, Internal Agent 전달) → 지속 확인(재인증·차단) → 연결 종료
- 설계 사실(사용 가능): TLS 1.3 mTLS, 비반출 키(Windows TPM / Android StrongBox·TEE), WireGuard 터널(TCP 대체 경로), OPA 기본 거부 + 관찰/집행 모드, 기기 상태 점검(OS 업데이트·백신·BitLocker·화면 잠금 / 패치·루팅·Play Integrity)
- **쓰지 않을 값**: 인증서 8시간(설계 예시일 뿐), 폐기 5초(값 없음), 잠금 5회/15분(값 없음), 신호 9종
- 플랫폼: Windows x64, Android. iOS 미확정
- 표준 문구: "CISA ZTMM v2.0 · NIST SP 800-207 기반 설계" (준수·인증 표현 금지)

### 표현 주의
- "AI 행동 모델": 문서 간 충돌. 현재는 규칙·정책 기반, 학습형은 고도화 예정 → **"사용자별 행동 기준선" 또는 "AI 고도화 중"** 정도로
- 특허: **출원 중**(심사 중, 1차 의견제출통지 받음). "특허 등록·특허 기술" 금지, "특허 출원"만. 출원번호가 문서마다 다름(10-2026-0159586 / 10-2026-0070986)
- CISA·금융 안내서: "Optimal 달성" 금지, "요건 지원"으로

## 4-3. 소식 자동 수집 방안 → **결정: C + D (링크 등록 + RSS), 2026-11-10**
| 방식 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 피드 위젯 | Tagembed·Elfsight·Walls.io 등이 LinkedIn 페이지 글을 퍼 와 삽입 코드 제공 | 설정이 가장 빠름 | 월 요금, 디자인이 위젯 모양, 외부 스크립트(속도·개인정보), 다른 카드와 따로 놀음 |
| B. LinkedIn 공식 API | Community Management API(`r_organization_social`)로 회사 페이지 글 읽기 | 완전 자동 | 제한 상품이라 신청·화면 녹화 심사 필요, 거절되면 같은 앱으로 재신청 불가, 심사 기간 미공개 |
| **C. 링크 등록 + 자동 카드 (추천)** | SNS에 올린 뒤 글 주소만 한 곳(구글 시트 또는 간단한 관리 화면)에 붙여 넣으면 사이트가 제목·이미지를 자동으로 읽어 카드 생성, 누르면 원문으로 이동 | 우리 디자인 그대로, 무료, 외부 기사·유튜브 큐레이션도 같은 방법 | 글마다 주소 붙여 넣기 한 번(약 10초) |
| D. RSS 자동 | YouTube 채널·네이버 블로그는 RSS가 있어 완전 자동 수집 가능 | 손이 전혀 안 감 | LinkedIn은 RSS 없음 |

**확정 세부 (2026-11-10)**
- 등록 위치: **구글 시트**. 한 줄에 주소 · 분류 · 한 줄 코멘트 · 게시 여부
- 채널: LinkedIn, YouTube(RSS 자동), Instagram·Facebook, X(트위터), Threads. YouTube 외에는 주소 붙여 넣기. X·Threads는 미리보기 정보를 잘 안 내주는 경우가 있어, 실패하면 플랫폼 아이콘 + 시트에 적은 제목으로 카드 표시
- **우선순위: SNS보다 보안 뉴스 기사 자동 수집이 먼저**

**보안 뉴스 자동 수집 (제안)**
1. 수집원: 보안 전문 매체의 공개 RSS(보안뉴스·데일리시큐 등, 제공 여부 확인 필요) + 필요하면 네이버 뉴스 검색 API(2026년 API 허브 이관·약관 개정 → 원문 확인 후 사용)
2. 키워드로 거르기: 제로트러스트, ZTNA, VPN, 인증, 망분리, 금융보안, 계정 탈취 등
3. **제외 목록 자동 적용**: 고객사·파트너 이름(KB국민카드, 롯데카드, 웰컴저축은행, 에어레인 등)이 들어간 기사는 후보에서 뺌
4. 몇 시간마다 구글 시트 「후보」 탭에 제목·매체·날짜·링크를 쌓음
5. 게시 방식: **완전 자동 게시 (2026-11-10 결정)**. 필터를 통과한 기사는 바로 사이트에 올라감. 대신 시트에 **「숨김」 체크**를 두어 문제 기사를 사후에 내리고, **제외 단어 목록도 시트에서 직접 수정**할 수 있게 함
6. 사이트에는 제목·매체·날짜·원문 링크만. 기사 본문·사진은 가져오지 않음, 사이트 페이지를 직접 긁는 크롤링은 하지 않음(저작권·약관)

- 추천 조합: **C + D**. YouTube·블로그는 자동(D), LinkedIn과 외부 기사는 주소 붙여 넣기(C). 나중에 LinkedIn API 승인이 나면 B로 바꿔 끼움
- 원칙: 외부 기사는 **제목·출처·날짜·우리 한 줄 코멘트 + 원문 링크**만. 본문·사진 복사 금지. 고객사가 언급된 사고 기사는 올리지 않음(AGENTS.md 5절)
